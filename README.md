# Repo — renlovecomputer's iOS Tweaks

![Repository mascot: dachshund wearing a tie](CydiaIcon.png)

This is my personal repository for jailbreak tweaks published under **renlovecomputer**.

**Compatibility statement:** Every tweak currently published here has been tested only on **iOS 16.7.16**. Other iOS versions, devices and jailbreak configurations have not been verified. No broader compatibility is claimed.

## Add to Sileo

Open **Sileo → Sources → +** and add:

`https://renlovecomputer.github.io/repo/`

## Packages

- **GraviApps 1.0.0-8** — shake-triggered Home Screen icon gravity, tilt control, and Battery Saving / Normal modes. Rootless `iphoneos-arm64`.
- **GlyphTime 1.1.8** — image-based Lock Screen clock with individual digit glyphs and optional animated GIFs. Rootless `iphoneos-arm64`.

Both packages list **renlovecomputer** as author and maintainer. Each has been tested only on iOS 16.7.16; all other configurations are unverified.
